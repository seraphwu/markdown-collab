# 功能需求－前端

1. 登入與權限：

- 第三方登入模組：整合 Google/Apple API，並串接手機簡訊驗證系統實施雙重認證。
- 相機與相簿權限：請求系統級權限，並須具備讀取照片 Matadata 中的經緯度功能。

2. Header 與全局導覽：

- 品牌 Logo：點擊「MapMo」字樣即刻回到地圖首頁。
- 搜尋列：位於 Logo 下方，提供地址輸入搜尋功能。
- 右側選單（個人檔案 icon）：點選後展開下拉選單，包含：「個人檔案、使用說明、幫助、垃圾桶、設定。」

3. 地圖首頁功能：

- 情緒過濾左側欄：
  - 垂直排列 8 個情緒按鈕。
  - 互動效果：被選中的情緒按鈕會放大顯示，並同步更新地圖上的色系。
- 分頁切換鈕（底部）：提供「相機」與「地圖」的快速切換開關。

4. 拍攝與編輯：

- 相機視窗：
  - 快門鈕居中，左側閃光燈開關，右側鏡頭反轉鈕。
  - 強制照片輸出比例為 1:1。
- 文字框：輸入區，限制 100 字以內。
- 控制項：左上角（＜）回上一步；右上角（Ｘ）退出上傳；右下角（ 。 ）送出上傳。

5. 個人檔案頁面結構：

- 地圖視窗：僅顯示使用者本人足跡地標。
- 照片網格：預設案日期排序（最新到最舊）。
- 篩選：點選地圖地標時，下方照片網格應自動過濾出該地點所有個人照片。
