# 使用者流程

1. **使用者流程** (用 1.然後空白)

   使用者開啟APP，依序以下流程：

   1. 登入與身份驗證：

      * 進入「登入畫面」。
      * **選擇登入方式**：支援Google、Apple登入或手機號碼登入。
      * **雙重認證**：若使用Google或Apple登入，系統要求必須綁定手機號碼進行驗證。
   2. 進入平台與導覽：

      * **首次登入教學**：第一次使用會顯示「使用說明」（可跳過）。
      * **雙重認證**：若使用Google或Apple登入，系統要求必須綁定手機號碼進行驗證。
      * **預設首頁**：登入後預設進入「相機拍攝畫面」，使用者可點擊下方切換鈕或右上角（X）進入「地圖首頁」

        <br />
      * 地圖探索流程：

        l   搜尋列：使用Header下方的搜尋列輸入地址進行定位搜尋。

        l   情緒過濾：點選地圖左側「情緒按鈕」，地圖將顯示該情緒色系的地標與照片。

        4.        貼文上傳流程：

        l   上傳方式：從相機分頁立即拍攝或點選進入個人檔案，從個人檔案中點選右下角固定懸浮按鈕（＋）上傳相簿照片。

        l   照片來源與檢核：

        n   立即拍：比例1:1，具備閃光燈與翻轉鏡頭功能

        n   相簿選擇：需詢問相簿存取權限，且照片必須含有「地理位置資訊」，否則無法上傳。

        l   編輯與填寫：

        n   確認地標地址是否正確。

        n   情緒標籤：從8個情緒按鈕中選擇一個當下心情（選填）。

        n   文字內容：選填，上限100字。

        n   日期位置：直接顯示在照片右下角xxxx/xx/xx。

        l   確認送出：點擊右下角（。）上傳，完成後自動跳回地圖首頁。

        5.        個人檔案管理：

        l   進入路徑：點擊右上角（個人檔案icon）圖示進入「個人檔案」。

        l   畫面佈局：

        n   上半部：顯示本人定位附近的範圍地圖與地標。

        n   下半部：顯示由新到舊的照片排序。

        l   互動邏輯：點選地標可篩選該地的照片；點選照片則進入完整內容頁，顯示情緒、文字、日期與地點）。
